# Shelf

Превращает сохранённые видео из Instagram, TikTok и Telegram в страницу с поиском: транскрипт речи, текст с экрана (OCR), кадры, саммари от LLM, теги, главное содержание и режим **«Места»**, который группирует все места из видео по городам и показывает их на карте.

Всё работает локально. [English](README.md) | Русский

## Важно

- Скачивание видео, особенно с куками браузера, может нарушать правила Instagram, TikTok и Telegram и привести к ограничению аккаунта. Используйте на свой риск и только для своих сохранённых видео.
- Куки читает локально `yt-dlp` (`--cookies-from-browser`). Инструмент никуда их не отправляет.
- Текст видео (подпись, речь, текст с экрана) уходит выбранному вами провайдеру LLM. С локальной моделью (Ollama, LM Studio) данные не покидают компьютер.
- Названия мест уходят в Nominatim (OpenStreetMap), чтобы найти координаты для карты, а плитки карты загружаются с openstreetmap.org.
- Первый поиск скачивает небольшую многоязычную модель (`paraphrase-multilingual-MiniLM-L12-v2`) с Hugging Face. Дальше поиск работает локально.

## Требования

Только macOS (OCR работает через Apple Vision и `ocrmac`), Python 3.11–3.13 (на более новых нет колёс `onnxruntime`), Node.js, ffmpeg и одна LLM: `claude` CLI (по умолчанию), ключ Anthropic API или любой OpenAI-совместимый эндпоинт.

## Установка

```bash
git clone https://github.com/DianaMak-Di/shelf.git && cd shelf
./setup.sh
.venv/bin/python server.py   # http://localhost:8765
```

Добавляйте видео кнопкой «+» в интерфейсе (ссылки по одной в строке) или кладите ссылки в `urls.txt`, затем нажмите «Синк». Чтобы использовать куки браузера при скачивании, один раз запустите вручную `python shelf.py fetch urls.txt --cookies chrome`.

## Источники

Источник определяется по ссылке, на карточке виден бейдж, а фильтр по источнику появляется, когда источников больше одного.

- **Instagram**: `instagram.com/reel/…`, `instagram.com/p/…`. Для части видео нужны куки (`--cookies chrome`).
- **TikTok**: `tiktok.com/@автор/video/…`, короткие `vm.tiktok.com/…`. Публичные видео скачиваются без кук. Некоторые посты TikTok блокирует по IP или региону, такие пропускаются с `FAIL`.
- **Telegram**: публичные посты каналов с видео, `t.me/канал/123`. Посты без видео (только текст или фото) пропускаются. Закрытые каналы (`t.me/c/…`) не поддерживаются.
- Видео старше года пропускаются (как и раньше).

### Сохранённое («Избранное» Telegram, избранное TikTok)

Синк начинается с `python shelf.py saved`, который добавляет новое сохранённое в `urls.txt`. Подключить оба источника можно в интерфейсе: окно **«Источники»** открывается само при первом запуске (у каждого источника есть кнопка **«Добавить позже»**), а потом доступно кнопкой в шапке.

- **«Избранное» Telegram**: видео и все ссылки на Instagram, TikTok и `t.me`, сохранённые туда за последний год. Один раз войдите в аккаунт: в **«Источниках»** или в терминале командой `.venv/bin/python shelf.py tg-login`. Понадобятся `api_id` и `api_hash` (создайте приложение на my.telegram.org → API development tools; они сохранятся в `config.json`), затем телефон, код входа и пароль 2FA, если он есть. Вход сохраняется в файле `telegram.session` в этой папке. Любой, у кого есть этот файл, может пользоваться вашим аккаунтом Telegram, поэтому никому его не передавайте и не коммитьте (он в `.gitignore`). Чтобы выйти, нажмите **«Отключить»** в «Источниках» или завершите сеанс в Telegram → Настройки → Устройства и удалите файл. Читаются только сообщения новее прошлого синка (`saved_state.json`). Видео из «Избранного» открывается как исходный пост, если его переслали из публичного канала, иначе как сообщение в приложении Telegram (`tg://`).
- **Избранное TikTok**: ссылки на профиль недостаточно. Список избранного TikTok никому снаружи приложения не отдаёт (даже если избранное открыто в профиле), и yt-dlp его не видит. Запросите данные в TikTok (Профиль → ☰ → Настройки и конфиденциальность → Аккаунт → Скачать данные, формат JSON) и загрузите архив в «Источниках» или распакуйте его и положите `user_data_tiktok.json` в эту папку. Каждый синк берёт из него ссылки. Для нового избранного загрузите свежий экспорт.

Видео, сохранённые до появления источников, получают `source=instagram` командой `python shelf.py migrate` (один раз; без неё интерфейс считает их Instagram).

Необязательный `collections.json` (см. `collections.example.json`) сопоставляет названия коллекций кодам видео. Названия коллекций становятся главными хэштегами.

## Настройка

Скопируйте `config.example.json` в `config.json` (`setup.sh` делает это сам). Без файла будут русский язык и `claude` CLI.

```json
{
  "language": "ru",
  "llm": { "provider": "openai", "base_url": "http://localhost:11434/v1", "strong": "llama3.1:70b", "fast": "llama3.1:8b" }
}
```

- `language`: `ru` или `en`. Определяет интерфейс, сообщения сервера, промпты и язык саммари и тегов. Транскрипты и текст с экрана остаются на языке оригинала. Чтобы добавить язык, скопируйте `lang/en.py` в `lang/<код>.py`.
- `provider`: `claude-cli` (по умолчанию), `anthropic` (ключ в `ANTHROPIC_API_KEY`) или `openai` (любой OpenAI-совместимый эндпоинт; ключ в `OPENAI_API_KEY`, для локальных серверов не нужен). Через `api_key_env` ключ берётся из другой переменной.
- `strong` / `fast`: модель для тяжёлых шагов (главное содержание, теги) и лёгких (саммари, сокращение).
- Если ответ не удалось разобрать, вызов сразу повторяется: `fast` -> `strong` -> `strong` (для сильных шагов `strong` три раза). Если все попытки неудачны, видео пропускается и повторяется при следующем синке.
- Смена провайдера влияет только на новые видео. Старые саммари и теги остаются.

## Экспорт в Obsidian

```bash
python shelf.py obsidian ~/Documents/MyVault/shelf
```

Записывает Markdown в указанную папку: заметка на каждое видео в `videos/`, страницы городов в `places/`, источников в `sources/` и коллекций в `collections/`, скриншоты в `attachments/`. Экспортируйте в подпапку хранилища, а не в его корень. С `--single` получится один файл `all.md` со всеми видео: без страниц-хабов и скриншотов.

Запускать можно сколько угодно раз. Перезаписываются только блок между `%% shelf:start %%` и `%% shelf:end %%` и свойства, которыми владеет инструмент. Ваш текст вне блока и ваши свойства сохраняются. Теги, которые сгенерировал инструмент, попадают в `shelf_tags` и в `tags`; теги, которые вы сами добавили в `tags`, остаются. Ничего не удаляется: заметки о видео, которых больше нет в базе, остаются на месте. Заметку можно переименовать или переложить внутри `videos/`. Заметку, которую вынесли из `videos/`, инструмент считает потерянной и создаёт заново.

## Команды

```
python shelf.py saved                               # новое из «Избранного» Telegram и экспорта TikTok -> urls.txt
python shelf.py tg-login                            # один раз: вход в Telegram
python shelf.py fetch urls.txt [--cookies chrome]   # аудио, подпись, транскрипт речи (Instagram, TikTok, t.me)
python shelf.py migrate                             # один раз: проставить source у старых видео
python shelf.py frames                              # кадры и текст с экрана
python shelf.py enrich                              # название, саммари, хэштеги, места...
python shelf.py keys                                # главное содержание
python shelf.py tagmap                              # сжать хэштеги до ~20 общих
python shelf.py places                              # один раз: дописать город и страну к местам старых видео
python shelf.py cities                              # один раз: привести города и страны к единому написанию на основном языке
python shelf.py geocode [--force]                   # координаты для карты (Nominatim, 1 запрос в секунду)
python shelf.py build                               # собрать интерфейс
python shelf.py obsidian <vault folder> [--single]   # экспорт в Markdown для Obsidian
python test_llm.py                                  # самопроверка повторов и конфига
python test_sources.py                              # самопроверка: ссылка -> источник и id
```
