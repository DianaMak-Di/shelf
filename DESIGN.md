# DESIGN.md

Дизайн-основа reels-tool: цвета, шрифт, отступы, радиусы, тени, анимации, темы. Статус: **утверждено автором 2026-11-11** (раздел «Решения» внизу). Спецификация переноса в код: `.design/specs/foundation-themes.md`.

Аудит, из которого это выросло: `.design/audit.md`. Варианты, из которых выбирали: `.design/sketches/foundation/index.html` (скриншот `foundation.png`).

## Принципы

1. **Контент цветной, интерфейс нет.** Цвет дают обложки рилсов. Хром нейтральный, один акцент.
2. **Один залитый акцент на вид.** Акцентом залита только главная кнопка экрана («Синк»). Ссылки акцентным текстом, остальное нейтральное.
3. **Только семантические токены.** В компонентах нет `bg-rose-100`, `#be123c`, `bg-white/90`. Если роли нет, добавляем токен.
4. **Обе темы равноправны.** У каждого токена светлое и тёмное значение, контраст проверен в обеих.
5. **Опираемся на shadcn.** Имена переменных shadcn сохраняем (`--background`, `--card`, `--primary`…), чтобы компоненты из `components/ui` работали без правок.

## Что есть сейчас (ui/src)

- Tailwind 4 + shadcn `base-nova` (base-ui), `@theme inline` в `ui/src/index.css`, цвета в OKLCH.
- Светлая тема своя: холодный нейтральный фон `oklch(.975 .002 260)`, белые карточки, синий акцент `oklch(.55 .21 262)`.
- `.dark` это сток shadcn neutral: акцент белый, синий пропадает. Класс `.dark` нигде не ставится, переключателя нет.
- Не используются: `--chart-*`, `--sidebar-*`, `--accent` (совпадает с `--muted`). Удалить.
- Хардкод вне токенов: палитра тегов `App.tsx:261-272` (10 оттенков Tailwind), маркер карты `#be123c/#f43f5e`, `text-emerald-600`, `bg-white/90`, градиенты `slate-300→500` на заглушках обложек, `#94a3b8` в попапе.
- Шрифт Inter Variable (`@fontsource-variable/inter`), корень 16px, `antialiased` на body. (Был Geist, заменён 2026-11-12 по выбору автора.)

Нейтральные с оттенком 260 (как сейчас в светлой). Контраст считан из OKLCH → sRGB, WCAG 2.x.

### Теги

- Обычный: фон `sunken`, текст `text`, число `text-muted`.
- Выбранный: фон `text`, текст `background`, `#` заменяется галочкой (ширина не прыгает).
- `aria-pressed` как сейчас. Цвет не единственный признак: галочка.

### Карта

- Маркер: `accent`, обводка 2px белая; приблизительный: заливка 20%, пунктир (как сейчас).
- Попап: `surface`, `text`, шрифт приложения, радиус lg, тень elevation-1.
- Тайлы OSM в тёмной теме остаются светлыми; затемнять фильтром не надо (портит подписи). Рамка карты `border`.

## Типографика

Inter Variable (`@fontsource-variable/inter`), веса 400 / 500 / 600. Ниже 18px не легче 400. Размеры в rem, межстрочные без единиц.

| Роль | Tailwind | Размер | Межстрочный | Вес | Где |
|---|---|---|---|---|---|
| caption | `text-xs` | 12px / .75rem | 1.35 | 400, 500 | мета карточки, счётчики, чипы, подсказки форм |
| body-sm | `text-sm` | 14px / .875rem | 1.5 | 400, 500 | текст карточки, кнопки, меню, поля на десктопе |
| body | `text-base` | 16px / 1rem | 1.5 | 400, 600 | заголовок карточки (600, межстрочный 1.4), поля на телефоне, длинный текст в деталях |
| heading | `text-lg` | 18px / 1.125rem | 1.3 | 600 | город в «Местах», заголовок окна |
| title | `text-xl` | 20px / 1.25rem | 1.3 | 600 | h1 страницы |

- Убрать `text-[15px]` с body: корень 16px, текст интерфейса 14px через классы.
- Убрать `text-[0.8rem]` из `button` size sm: 12px (caption) или 14px.
- Числа (счётчики, лайки, даты в списках): `tabular-nums` (сейчас частично есть).
- Мера: текст карточки и деталей `max-width: 68ch`.
- Заголовки с переносом: `text-wrap: balance`; саммари: `text-wrap: pretty`.
- Подписи разделов карточки («Параметры», «Рецепт»): body-sm 500 `text-muted`, без `capitalize` в CSS, регистр в данных.
- Поля ввода: `text-base md:text-sm` (уже так в shadcn, iOS не зумит).

## Отступы

Базовый шаг 4px (Tailwind). Внутри группы в 2 раза меньше, чем между группами.

| Токен | px | Tailwind | Где |
|---|---|---|---|
| space-1 | 4 | `1` | иконка-текст, число в теге |
| space-2 | 8 | `2` | внутри группы: теги между собой, кнопки в ряду, строки меты |
| space-3 | 12 | `3` | padding карточки, между контролами разной природы |
| space-4 | 16 | `4` | между группами внутри экрана, поле страницы на телефоне |
| space-6 | 24 | `6` | между разделами, колонки (сайдбар / контент), padding окна |
| space-8 | 32 | `8` | поле страницы на десктопе сверху |

`1.5` (6px) оставить только для зазора тегов, если 8 будет слишком редко. Остальные значения не вводить.

Тап-зоны: на `pointer: coarse` высота контролов 44px (или расширение зоны псевдоэлементом), на десктопе 32px.

## Радиусы

Концентричность: внешний = внутренний + отступ.

| Токен | px | Где |
|---|---|---|
| radius-sm | 6 | чип источника, обложка внутри карточки, мини-обложки в «Местах» |
| radius-md | 10 | кнопки, поля, селект, сегменты переключателя (8 внутри дорожки с отступом 2) |
| radius-lg | 18 | карточки, панели (сайдбар, поиск), поповеры, окна, карта |
| radius-full | 9999 | теги |

Проверка: обложка 6 + padding карточки 12 = 18. Контролы 10 + padding панели поиска 8 = 18 (сейчас 6, станет 8).

В `index.css`: `--radius: 0.625rem`. Существующие множители в `@theme inline` тогда дают ровно нашу шкалу: `rounded-sm` = 6 (radius-sm), `rounded-lg` = 10 (radius-md, его уже используют кнопки и поля shadcn), `rounded-2xl` = 18 (radius-lg), `rounded-full`. Классы `rounded-md`, `rounded-xl`, `rounded-3xl`, `rounded-4xl` и произвольные `rounded-[14px]` в приложении не использовать.

## Поверхности и тени

| Уровень | Что | Светлая | Тёмная |
|---|---|---|---|
| 0, плоско | карточки, панели, карта | `border: 1px solid var(--border)`, без тени | то же |
| 1, всплывает | поповер, меню селекта, попап карты | `0 1px 2px oklch(0 0 0 / .06), 0 4px 16px oklch(0 0 0 / .08)` + рамка `border` | без тени, `surface` + рамка `border`, фон на шаг светлее: `oklch(.25 .01 260)` |
| 2, окно | Dialog | `0 8px 32px oklch(0 0 0 / .16)`; подложка `oklch(0 0 0 / .3)` | подложка `oklch(0 0 0 / .6)`, рамка `border` |

- Под тенью `border: 1px solid transparent`, чтобы в forced-colors осталась граница.
- Обложки: `outline: 1px solid oklch(0 0 0 / .1); outline-offset: -1px` (тёмная `oklch(1 0 0 / .1)`).
- Кнопка «play» на обложке: `oklch(1 0 0 / .9)` и `oklch(.21 .01 260)` в обеих темах (поверх фото, тема не важна) — единственное разрешённое исключение из токенов, вынести в `--on-media`.
- Заглушка без обложки: `sunken` + иконка `text-muted`, без градиента slate.

## Анимации

| Токен | Значение | Где |
|---|---|---|
| duration-fast | 120ms | hover, смена цвета, нажатие, тег вкл/выкл |
| duration-base | 200ms | появление поповера и окна, раскрытие карточки |
| duration-exit | 150ms | исчезновение поповера и окна |
| duration-slow | 300ms | редкое: первая загрузка списка, успех синка |
| ease-out | `cubic-bezier(0.2, 0, 0, 1)` | всё |
| press-scale | 0.96 за 150ms | кнопки (не disabled), под `motion-safe` |

- Переходы только по названным свойствам (`transition-property: background-color, color`), не `all`.
- Масштаб, сдвиг, blur и `flyTo` карты только под `prefers-reduced-motion: no-preference`; при reduce только opacity, карта `setView`.
- Спиннер синка `motion-safe:animate-spin` (уже так), рядом текст шага.
- При переключении темы временно отключать transitions (иначе всё «перетекает»).

## Темы: как переключать

- Оставить механизм shadcn: класс `.dark` на `<html>`, `@custom-variant dark (&:is(.dark *))` (уже в `index.css`).
- Значение: `light | dark | system`, по умолчанию `system`. Хранится в `localStorage`.
- Инлайн-скрипт в `ui/index.html` до загрузки бандла ставит класс, чтобы не мигало: `system` → `matchMedia('(prefers-color-scheme: dark)')`, плюс слушатель изменений.
- `<meta name="color-scheme" content="light dark">` и `color-scheme` на `:root`/`.dark`, чтобы скроллбары и нативные контролы тоже темнели.
- Переключатель: иконка в шапке (солнце/луна/монитор), меню из трёх пунктов. Новые строки в оба `lang/*.py`.

## Решения

2026-11-11, выбор автора по `.design/sketches/foundation/foundation.png`:

| Развилка | Выбрано | Почему |
|---|---|---|
| Акцент | синий `oklch(.55 .21 262)`, как сейчас | уже есть в продукте и читается как действие; цвет только для действия |
| Теги | нейтральные (`sunken` + `text`), выбранный инвертирован, галочка вместо `#` | цвет не спорит с обложками и акцентом, «выбрано» всегда выглядит одинаково |
| Тёмная тема | холодный графит, оттенок 260 | одна семья со светлой темой, переход между темами без смены характера |
| Плотность ленты | сетка в 2 колонки от 1200px | 122+ рилса быстрее сканировать, длина строки сама приходит в норму; реализуется в задаче про экраны, не в основе |

2026-11-12:

| Развилка | Выбрано | Почему |
|---|---|---|
| Шрифт | Inter Variable вместо Geist | 2026-11-12 шрифт Inter — выбор автора |

Отклонено: чернильный и оранжевый акцент, цветные теги по хешу, нейтральный серый и OLED в тёмной теме, список и компактный список.
